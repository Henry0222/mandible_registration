## 打包修正

PyInstaller 原配置从环境中已安装的包收集 SVG，可能遗漏当前源码中新加的流程图。现在应用资源和模块均直接从当前 checkout 收集，通用配准核心继续使用已安装的正式依赖。打包脚本逐项校验当前 SVG、图标与冻结包内文件的 SHA-256，缺失或版本不一致即停止生成 ZIP。

本次已确认新版流程 SVG 与源码逐字节一致，冻结模块包含 `section_geometry`、`section_viewer`、`view_interaction`。使用说明同步改为剖面测量、双窗口和当前鼠标操作。

## 平行投照与窗口比例

- 上方三维改为平行投照，缩放通过改变视野范围实现，等长线段不会随深度变化而改变投影长度。剖面保持平行投照。
- 重置和方向视图按可见模型的投影范围取景，保留双侧 T0 髁突中心中点作为旋转中心；远离模型包围盒中心的旋转中心也不会导致模型被裁掉。
- 首次打开时左侧信息栏与右侧视图区宽度默认 1∶4，右侧上下区域高度默认 3∶2。模型预设按钮分成两行，文字可换行；启用剖面不会挤掉默认比例。拖动分隔条后，隐藏并重新打开窗口保留调整。
- 原生 1440×940 窗口实测左右宽度为 287 / 1149，上下高度为 502 / 336，差异仅为像素取整；侧栏横向滚动范围为 0。当前真实双侧病例取点、旋转、缩放、平移、导出、共享读取及关闭验证通过。
