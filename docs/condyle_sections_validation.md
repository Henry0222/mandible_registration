## 精确交互定义

| 操作 | 行为 |
| --- | --- |
| 初次启用 | 各侧从已保存髁突面片的面积加权中心建立 ROI，中心变换到 T0 世界坐标，半径固定 20 mm；未保存侧显示空状态 |
| 初始方向 | 世界 YZ 平面，法向 +X，屏幕上方 +Z；世界参考来自上颌口扫.1，界面明确标注非解剖方位 |
| 左键拖动 | 同时旋转相机与剖面方向；围绕 ROI 中心，保持带符号偏移值 |
| 滚轮正向 | 沿当前相机观察方向向场景内部移动；默认 0.5 mm/格，可选 0.1、0.5、1 mm；范围 −20 至 +20 mm |
| 右键拖动 | 平移视野，不改变物理剖面；三维圆盘代表剖面与固定 ROI 球的交集 |
| + / − | 缩放视野，不改变剖面位置或测量长度 |
| 复位 | 恢复世界初始方向、零偏移和平移 |
| 距离取点 | 勾选后左键短按，在 6 个逻辑像素内吸附到真实可见截线；隐藏模型不参与取点；标签只有距离 |
| 改变剖面 | 清除未完成的点；已完成记录只在原平面显示，可从记录下拉框返回原平面 |
| 三维同步 | 左绿、右粉圆盘实时显示位置与方向，不参与骨面取点或相机包围盒计算 |

左右剖面的显隐独立于上方三维，模型颜色跟随三维颜色修改。记录保存世界坐标、来源模型、对应已加载 STL 的面片编号、平面法向、中心和偏移。

## 性能实现与实测

三个视图共用同一批已加载源网格；源 PolyData 由主查看器持有，剖面派生紧凑 ROI，不复制或重读完整 STL。缓存建立在线程中只处理 NumPy 数组，VTK 窗口、actor、定位器在 Qt 主线程构建。

ROI 以 65,536 面分块先做包围盒排除，再计算三角面与球体的真实相交；能保留三个顶点均在球外但面穿过球体的情况。VTK 只剖切缓存的 ROI，输出线段再解析裁剪到球内，不补面或闭合断口。原始面片编号通过点击时的 ROI 定位器回查，避免 VTK 快速剖切器丢失 cell data 导致错误来源。

交互更新合并到约 33 ms，一次只更新活动侧。交互时关闭剖面 FXAA 和三维深度剥离；松键或滚轮停止 140 ms 后完整刷新并恢复。取点为点图元，测量为简单线段，不构建球体或管状网格。

| 原生 Windows Qt/VTK 冒烟 | 初次读模型 | 启用 ROI 与剖面 | STL 读取次数 | 主动剖面与三维刷新耗时 |
| --- | ---: | ---: | ---: | --- |
| 真实旧双侧病例，无上颌骨 | 2.026 s | 2.144 s | 2，每文件一次 | 左中位数 16.63 ms、最大 46.21 ms；右中位数 16.51 ms、最大 27.26 ms |
| 合成双侧、含开口固定骨面 | 0.396 s | 0.761 s | 3，每文件一次 | 左中位数 16.82 ms；右中位数 16.59 ms |
| 合成单侧、另一侧空状态 | 0.405 s | 0.523 s | 3，每文件一次 | 中位数 16.59 ms |

真实病例每次颌骨 1,112,304 面；左 ROI 为 T0 59,597 面、T1 53,968 面，右 ROI 为 T0 63,687 面、T1 63,411 面。上述数据为当前机器小样本冒烟，包含首次渲染波动，不代表所有病例或显卡的帧率保证。

新进程主界面模块导入实测 0.296 s，VTK 和两个 section 模块均未加载。首次启用、旋转、平移、滚轮、取点、隐藏重开均验证没有新增 STL 读取。

## 验证结果

- 下颌项目完整测试：**129 passed，17.98 s**。
- 父项目完整测试：**121 passed，20.32 s**。
- 几何：三角面球相交、边界相切、全外顶点穿球、空 ROI、退化面、截线严格 20 mm 边界、旋转正交性和沿视线毫米偏移。
- 交互：真实 Qt 左拖/右拖/滚轮/短按事件，拖动不误取点，两侧互不影响，同步三维截面，缩放和平移后仍保持已知 10 mm 距离，隐藏轮廓无法取点，标签不含编号。
- 生命周期：懒初始化、只启用单侧、空 ROI、缓存复用、可复用窗口隐藏重开、选区中心变更失效处理和 VTK 清理。
- 兼容：旧项目及实验旁路字段忽略、可选上颌骨固定 T0、原有选区单侧保存、两次下颌骨测量、方向轴与定向查看、暗色系统下的浅色主题。
- 原生冒烟：合成双侧、合成单侧、真实旧双侧病例，以及原有 `check_viewer.py --native --dark-system` 的主界面/输入窗口/三维距离/四点角度/CT 配准查看全部通过。
- `git diff --check` 通过。

另一个更早的旧结果保留了已有 CT 坐标不一致告警，因此未作为有效几何病例计入通过清单；没有绕过原有坐标门槛。

## 复现与证据

在本项目目录使用 `.venv-integration\Scripts\python.exe`：

```powershell
.venv-integration\Scripts\python.exe -m pytest --basetemp=.pytest-tmp/sections-check
.venv-integration\Scripts\python.exe scripts/check_sections.py <输出目录> --native
.venv-integration\Scripts\python.exe scripts/check_sections.py <输出目录> --native --single-side
.venv-integration\Scripts\python.exe scripts/check_sections.py <输出目录> --native --project <历史project.json>
.venv-integration\Scripts\python.exe scripts/check_viewer.py <历史project.json> <输出目录> --native --dark-system
```

当前工作区证据位于父目录 `analysis_output/condyle_sections_20260909/`：`mandible-tests.log`，`final-legacy-bilateral/`、`final-synthetic-bilateral/`、`final-synthetic-single/` 下的 `smoke_result.json`、`measurements.json` 与三状态截图，以及 `final-main-regression/` 的原有查看流程截图。真实病例文件没有纳入源码交付。

## 仍需真实病例确认

现有可用旧病例不含颞骨关节窝，上颌骨通路目前由合成开口骨面验证。仍需包含双侧颞骨关节窝、与原始 CT 同坐标的真实 STL，确认选区中心与 20 mm 范围是否覆盖目标区、人工剖面方向选择、轮廓手选距离与独立软件测量的一致性，以及更多高密度/破损网格的响应。孔洞处保持原始缺失；本实现没有推断连续关节窝，不能据此生成原实验性骨性关节间隙统计。
