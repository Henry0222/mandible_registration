# 髁突查看器交互与窗口修订验证

时间：2026-09-09T23:55:00+08:00。适用于当前 v1.1.0 源码；未打包 EXE，未提交或推送。

以上为当时的源码验证快照；后续 EXE 构建和发布包校验见 [v1.1.0 打包记录](release-v1.1.0.md)。

## 交互与布局

- 三维旋转中心取左右 T0 髁突中心中点；单侧时取已有侧，无选区时回退到当前视图中心。相机平移后仍绕固定髁突中心旋转。重置及定向查看按该中心适配模型边界。
- 三维和剖面统一为左拖旋转、中拖平移、右拖缩放（上拖放大、下拖缩小）。三维滚轮缩放，剖面滚轮保持沿当前视线移层，默认每格 0.5 mm。
- 双侧剖面侧栏只保留启用按钮。已启用的截面始终显示于三维，不再有显示开关；截面恰好移到球边界时交集半径为零。
- 删除三维手动标记、骨间距离、四点角度和相应拾取定位器。保留髁突中心自动位移线、剖面取点测距及统一导出。旧测量 JSON 字段 `measurements` 保留为空，剖面记录仍使用 schema 4 的 `condyle_sections`。
- 查看器改为无父窗口的独立顶层窗口，与主窗口拥有不同原生窗口句柄和独立最小化行为。同一进程继续共享缓存。主窗口关闭后，可见查看器继续运行；有未导出测量的隐藏查看器会恢复显示，交由用户关闭。

## 位移与旋转显示

按用户指定的共同 XYZ 约定解释位移：左侧 +X / 右侧 −X 为外移，反向为内移；两侧 −Y 为前移、+Y 为后移，+Z 为上移、−Z 为下移。方向、距离使用黑色大字，XYZ 数值及与正轴的夹角使用灰色小字。已删除原中心定义句和末尾方向说明句。

从 −X 观察、屏幕上方为 +Z 时，顺时针为下颌骨顺旋。为避免把 Y/Z 旋转误报为顺逆旋，黑色主值显示有符号 X 向分量，灰色保留三维总旋转角。两者均写入髁突分析记录。

对于共同坐标中的相对刚体旋转矩阵 R，X 向分量为 `atan2(R[2,1] - R[1,2], R[1,1] + R[2,2])`，等价于四元数的 X twist。正值为顺旋，负值为逆旋；投影退化或 180° 的方向歧义不强行归类。真实旧病例示例为顺旋 3.03°、三维总角 3.24°。

## 启用性能

原 ROI 筛选会按侧、按模型展开全部三角面的三维顶点。新版先计算顶点在 ROI 立方体六个方向的边界标记，通过三个顶点的按位与排除远处面片，只对候选面执行精确球相交，继续保留三个顶点都在球外但面穿球的情况。

同时删除已经无用途的三维整网格拾取定位器，剖面定位器延迟到实际取点，左右截面添加后合并三维刷新。没有增加 STL 读取或降低 ROI / 截线精度。

同一真实旧病例，每次颌骨 1,112,304 面：

| 项目 | 首版 | 当前 |
| --- | ---: | ---: |
| 双侧剖面启用 | 2.144 s | 0.747 s（另一次为 0.854 s） |
| 左侧 T0 / T1 ROI 面数 | 59,597 / 53,968 | 59,597 / 53,968 |
| 右侧 T0 / T1 ROI 面数 | 63,687 / 63,411 | 63,687 / 63,411 |
| STL 读取 | 2 次，各文件一次 | 2 次，各文件一次 |
| 当前交互中位数 | — | 左 16.47 ms / 右 16.59 ms |

当前启用时间约减少 65%；这是本机小样本，不是所有机器的保证。首次模型读取独立计时为 2.034 s。该真实病例不含上颌骨；含固定上颌骨的单侧合成冒烟启用为 0.451 s，三份 STL 各读取一次。
